# LDrago Training

Neural models, custom BPE tokenizer, and training/evaluation harnesses for LDrago CLI.
- LDragoCoder: Custom Transformer architecture (pure PyTorch) with GQA, RoPE, RMSNorm, SwiGLU.
- LDragoDesigner: Custom State-Space Model / Mamba architecture (pure PyTorch) with selective scan recurrence and depthwise convolution.
- Custom Byte-Pair Encoding (BPE) tokenizer from scratch with special domain tokens.
